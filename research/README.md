# Дослідницькі матеріали

У цій папці зберігаються попередні версії даних, проміжні результати опрацювання та контрольні звіти. Вони залишені з початковими назвами для простежуваності дослідження та порівняння етапів підготовки.

Карта не завантажує файли з цієї папки. Єдиним робочим набором вебзастосунку є `../roads.geojson`.

## Вміст

- `roads-0.geojson`, `roads-1.geojson`, `roads-2.geojson` — послідовні проміжні варіанти об'єднаного шару;
- GeoJSON із назвами `Категорії_доріг_Україна_2017_…` — етапи виправлення геометрії, заповнення пропусків і додавання кількості смуг;
- `Категорії_доріг_Україна_усі_джерела (1).csv` — зведена таблиця записів з усіх досліджених джерел;
- `Реєстр_джерел_категорій_доріг_Україна.csv` — реєстр джерел, URL і приміток;
- `Покриття_категорій_доріг_по_областях.csv` — агреговане покриття за областями;
- `OSM_georeference_v4_report.csv` — звіт про геоприв'язку записів за OpenStreetMap.

Умови повторного використання даних і вимоги до атрибуції наведені в [`../DATA_LICENSE.md`](../DATA_LICENSE.md).
